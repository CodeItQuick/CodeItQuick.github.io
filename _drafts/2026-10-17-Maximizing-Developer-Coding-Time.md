# Introduction

# Developers Do More Than Code
* Invisible Work - Product Work & Fixing Things
  * Platform / Infrastructure Work, Architecture & System Evolution
  * Quality Work, Support & Collaboration, and Discovery & Planning Work
  * Improve & Keep it Current
* How can we "Automate the Boring Stuff"
* Free up developers to do engineering (higher value work? I don't know what word fits here)

# Eliminate or Reduce Unnecessary Work
* reduce process? meetings, reporting, coordination? (this work seems _necessary_ to me though)
* Challenge how frequently recurring activities need to happen
* Address underlying problems rather than repeatedly managing symptoms

# Automate Repetitive Activities
* Deployment Dashboard - replace 2-3 hours of daily work with a dashboard (minimal time investment to setup)
* Automated testing, release reporting, environment setup
* AI dramatically reduces the cost of creating small internal tools

# Delegate Work and Enable Self-Service
* Identify Tasks that don't require developer expertise
* Transfer appropriate responsibilities to QA, product, support, or operations
* Create dashboards and tools that eliminate recurring requests to developers
